# Secure Password Manager & Strength Checker

## Overview

This project is a Secure Password Manager developed using Python and Tkinter. It helps users create, analyze, encrypt, and decrypt passwords securely. The application provides real-time password strength analysis and offers recommendations for creating stronger passwords.

## Features

* Password strength evaluation (Weak, Medium, Strong)
* Real-time password analysis
* Password length tracking
* Detection of repeated characters
* Detection of special characters
* Secure password encryption using Fernet encryption
* Password decryption functionality
* User-friendly graphical interface built with Tkinter

## Technologies Used

* Python
* Tkinter (GUI)
* Cryptography Library (Fernet)
* Regular Expressions (re)
* Collections Module

## How It Works

1. The user enters a password.
2. The system analyzes the password based on:

   * Length
   * Uppercase and lowercase letters
   * Numbers
   * Special characters
3. The password strength is displayed instantly.
4. Users can securely encrypt the password before storing it.
5. Encrypted passwords can be decrypted when needed.

## Benefits

* Encourages users to create strong passwords.
* Demonstrates basic cybersecurity concepts.
* Provides secure password storage through encryption.
* Easy to use and suitable for beginners learning Python GUI development.
